# Task 4 Evidence: BorderWise AI Financial Copilot

## 1. Overview
The BorderWise AI Financial Copilot provides a decision-support conversational copilot on top of the deterministic FastAPI financial engine. It interprets student questions across international borders, invokes validated backend tools, and explains results with numerical proof, assumptions, and uncertainty.

### Registered Approved Tools (`app.ai.tools`)
1. `get_student_overview`: Extracts student accounts, tuition schedule, and living expenses.
2. `calculate_forecast`: Calls the 90-day cash-flow simulation engine; distinguishes liquid actual balances from projected events.
3. `calculate_funding_gap`: Evaluates multi-currency positions, shortfall amounts, and cross-currency remedies with dated FX quotes.
4. `compare_transfers`: Compares provider fees (upfront wire fee + FX margin markup) and identifies highest recipient amount.
5. `simulate_delayed_income`: Evaluates scenarios where scholarships or TA stipends arrive late.
6. `get_action_recommendations`: Returns prioritized, structured next steps.

## 3. Safety Guardrails & Policy

- **No Autonomous Money Movement**: Any request asking to send money, transfer funds, or authorize transactions is refused with:
  *"BorderWise AI is an advisory copilot and cannot authorize or execute actual money transfers. All transactions must be manually initiated through your authorized banking provider."*
- **Prompt Injection Defense**: Refuses attempts to bypass instructions, ignore system prompt, or dump backend secrets/environment variables.
- **Simulation Preview & Explicit Human Confirmation**: Consequential simulated changes return `requires_confirmation: True` and a structured `confirmation_preview` object requiring user confirmation before action plan updates.
- **Data Completeness & Assumptions**: All responses explicitly report active assumptions, data completeness scores, and quote timestamps.
- **No Hallucinated Arithmetic**: All numerical figures in responses are sourced directly from tool outputs, not generated by an LLM.
- **Deterministic Offline Fallback**: If external LLM API keys are absent, the copilot operates smoothly in deterministic mode (`is_demo_mode: True`).
